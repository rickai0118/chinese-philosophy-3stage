# /sanjie — acpte-tod 的中文别名

> **这是个 alias skill**：本 skill 不包含完整推理规则——所有规则、触发钩子、红线检查点、金句库都从父目录 `../SKILL.md` 继承。

## 调用方式

```
/sanjie [用户问题]
```

与 `/acpte-tod [用户问题]` **完全等价**。

## 何时用

- 中文用户偏好**简短中文名**：`sanjie` = "三阶"，比 `acpte-tod` 更直观
- 想在中文 prompt 里**更符合中文习惯**的引用

## 三种命令名对比

| 命令 | 字符数 | 适合 |
|---|---|---|
| `/cp3` | 4 | 国际通用感、英文/混合 prompt |
| `/sanjie` | 6 | 中文 prompt、直观 |
| `/acpte-tod` | 9 | 完整名、显式引用 |

三者指向同一套推理规则——**完全等价**。

## 实现机制

Claude 收到 `/sanjie` 时，应按 `../SKILL.md` 的完整规范执行：

1. 读 `../SKILL.md` 加载三阶推理规则
2. 读 `../references/quotes-en.md` 加载 22 句英文金句（如需）
3. 按场景自动识别语言（中文 → 第一档；英文 → 第四档）
4. 应用红线检查点（心理健康 / 法律 / 重大财务）
5. 按场景优先级确定三阶顺序

## 与 /cp3、/acpte-tod 的差异

**零功能差异**。只是命令名不同。
